# BeamNG Mod — Bug Type 1 (VW/AW)

This repository contains the complete source files for the 1963 Volkswagen Type 1 mod for BeamNG.drive. There are two versions, which are completely identical apart from their branding.

### Repository‑Friendly variant (AW)
Uses fictional branding and is the variant officially published on BeamNG mod‑repository.
For The latest release and official donwload look [**HERE**](https://www.beamng.com/resources/aw-type-1.36664/reviews#review-66223-569221).

### Real‑Branding variant (Volkswagen)
Uses real branding and is the original, iconic mod found in the official forum thread.
For The latest release and official donwload look [**HERE**](https://www.beamng.com/threads/1963-volkswagen-bug-feat-herbie-the-love-bug-dynamic-horsepowers.52497/).

## Repository Layout

- `bug/` -  Main mod source wotj real-branding
- `bug-aw/` - Specific files for the repository-frindly variant
- `assets` - Images and logos
- `build/` - Build and publishing utilities
